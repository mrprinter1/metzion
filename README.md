# מציאון

תוסף לדפדפן שמסמן ביד 2 (ובהמשך בפייסבוק מרקטפלייס) רכבים שעלו לאחרונה במחיר נמוך מהמחירון. מציאות נמכרות מהר, אז המהירות היא העיקר.

## החלטות

- **תחום:** רק רכבים כרגע.
- **מוצר:** תוסף לכרום במחשב, אחר כך תוסף לספארי באייפון.
- **מקור מודעות:** יד 2, מהדפים שהמשתמש עצמו מחפש בהם.
- **מחיר השוואה:** המחירון של יד 2, כי הוא שונה מלוי יצחק.
- **שרת:** לא נדרש ללוגיקה. התוסף רץ אצל כל משתמש.

## שלבי עבודה

עוברים לשלב הבא רק אחרי שהקודם עובד.

1. **חקר (במחשב)** - איך יד 2 בנוי מאחורי הקלעים. ראו [docs/research.md](docs/research.md).
2. **תוסף בסיסי לכרום** (שבוע עד שבועיים)
   - לקרוא את המודעות שעל המסך ולשלוף דגם, שנה, יד, קילומטראז', מחיר וזמן עלייה.
   - למשוך מחיר מהמחירון פעם אחת לכל שילוב של דגם ושנה, ולשמור בזיכרון.
   - לסמן כל מודעה בתגית (למשל "15% מתחת למחירון") ולהבליט מודעות שעלו בשעה האחרונה.
   - מונה שימוש: משתמשים, חזרות ומציאות שנמצאו.
3. **בדיקה עם משתמשים בחינם** - סוחר רכב ועוד כמה אנשים. לשאול איפה הם מחפשים (מחשב או נייד) וכמה היו משלמים.
4. **תוסף לספארי באייפון** - מק עם Xcode וחשבון מפתח של אפל ($99 לשנה). המרת תוסף הכרום והעלאה לאפ סטור.

## כסף

מתחילים בחינם ומחליטים על מחיר לפי נתוני שימוש. אפשרות לבדיקה: כרטיס חיפוש חד-פעמי לפרטיים ומנוי חודשי לסוחרים. גביית כסף תדרוש שרת קטן שבודק מי שילם.

## סיכונים

- **תלות ביד 2:** שינוי באתר שלהם יכול לשבור את התוסף.
- **תנאי שימוש:** יד 2 אוסרים שימוש אוטומטי בשירות, ומשיכת המחירון מספיק קרובה לגבול הזה.
- **נייד:** בכרום לטלפון אין תוספים, והאפליקציה של יד 2 לא מושפעת מהתוסף.
